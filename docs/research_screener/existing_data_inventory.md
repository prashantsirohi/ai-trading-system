# Persistent screener existing-data inventory

- **Purpose:** Evidence-backed map of repository datasets considered for the persistent screener.
- **Audience:** Data engineers, reviewers, and canary operators.
- **Last verified:** 2026-08-10
- **Source of truth:** Read-only inspection of configured runtime stores and the repository adapters named below.

Base inventory date: 2026-08-09; E2E identifier-transition evidence was reverified on 2026-08-10. Paths are resolved through `get_domain_paths()` and are shown relative to `$DATA_ROOT`; the inventory inspection itself is read-only.

## Gap matrix

| Required contract | Current state | Phase 0 action |
|---|---|---|
| Combined NSE+BSE universe independent of an index | Not present locally | acquire dated NSE CM MII combined master and freeze it |
| Company/security/listing topology and effective-dated identifiers | current broker symbol rows only | isolated screener masters/history, sourced from frozen official files |
| Official dated full/free-float market cap | unavailable in trusted local stores | implemented fixed NSE quote/BSE active-master adapters; all 17 canary outcomes resolved on 2026-08-10 |
| Full corporate-action taxonomy | local adjustment store remains split/bonus-oriented | implemented fixed NSE/BSE taxonomy adapter and reconciliation; unmatched required events become `ADJUSTMENT_INCOMPLETE` |
| Filing-backed normalized annual/quarterly facts | secondary-derived local facts lack hashes/URLs | implemented NSE/BSE XBRL acquisition and versioned normalization; below-contract history remains queued for repair |
| Bank and business-specific KPI schemas | absent from existing stores | versioned definitions persist; observations remain `NOT_DISCLOSED` until filing-backed acquisition |
| Immutable screening history | absent | new `$DATA_ROOT/research_screener/control_plane.duckdb` |

The inventory decision is to isolate the canary control plane from `control_plane.duckdb`, `execution.duckdb`, and the daily pipeline. Existing stores are opened read-only.
